# Business Analytics

SaaS-style business intelligence dashboard built with React, TypeScript, Vite, Tailwind CSS, Recharts and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy to Vercel

Import this folder/repository into Vercel. Framework preset: Vite. Build command: `npm run build`; output directory: `dist`. `vercel.json` includes SPA fallback routing.

All demonstration data is generated locally. Settings and order status edits persist in `localStorage`.
